# Сайт Dope Music Studio & Label

Многостраничный статический сайт студии звукозаписи Dope Music (Пермь) по брендбуку
«Dope Music Studio + Label new visual identity» (Behance, июль 2025).
Без сборщиков и фреймворков: открой index.html в браузере, и всё работает.

## Страницы

| Адрес | Что это |
|---|---|
| / | Главная: афиша, маршрут артиста, выписка из прайса |
| /studio/ | Студия: автоматизация, порядок сессии, опись тракта, цены |
| /label/ | Лейбл: релизный цикл, приём демо |
| /production/ | Продакшн: услуги, карусель макетов, процесс |
| /services/ | Полный прайс трёх направлений и FAQ |
| /booking/ | Бронь: калькулятор, слоты 24/7, заявка в Telegram |
| /contacts/ | Контакты, схема квартала, часы работы |
| /terms/, /privacy/ | Оферта и политика конфиденциальности |

Каждая страница лежит папкой с index.html внутри: адреса без .html работают и на GitHub Pages, и на локальном сервере.

## Структура

- assets/css/main.css: вся дизайн-система (токены в :root).
- assets/js/main.js: меню, появление листов, дата-штампы.
- assets/js/booking.js: калькулятор и отправка заявки.
- assets/fonts: Mulish и Martian Mono, сабсеты cyr / lat / lat-ext (в lat-ext живёт знак ₽).
- docs/brand-guidelines.md: правила бренда для веба. docs/PLAN.md: запись сборки.
- PRODUCT.md и DESIGN.md: продуктовая истина и описание визуальной системы.

## Карта в контактах

Плашка карты работает в два шага. Сначала видна наша схема квартала (SVG), по кнопке
«Показать карту Яндекса» на её место встаёт iframe с карточкой организации
(yandex.ru/map-widget/v1/?oid=183475169094&ol=biz). До нажатия к Яндексу не уходит ни одного
запроса, поэтому политика конфиденциальности остаётся честной. Цвет карты приводится к бумаге
фильтром и слоем var(--paper) в режиме multiply: логотип и ссылки Яндекса остаются видимыми.

## Кэш

Стили и скрипты подключены с меткой версии: main.css?v=ДАТА. GitHub Pages отдаёт файлы с
max-age=600, и без такой метки гость до десяти минут видит старую сборку. Меняете css или js:
поднимите метку во всех html сразу, иначе правки не доедут.

## Как принимаются заявки

Бэкенда нет. Форма брони собирает текст заявки, копирует его в буфер и открывает
чат студии в Telegram (@DOPEMUSIC_PERM): гость вставляет и отправляет. Черновик
формы хранится в localStorage браузера гостя и никуда не передаётся.

## Что заменить перед запуском (помечено в текстах как «от» или «уточняется»)

1. Ставки прайса на services.html, booking.html (и в RATES внутри assets/js/booking.js).
2. Условия лейбла: сплит 70/30, сроки ответа на демо.
3. Опись оборудования на /studio/ соответствует реальному тракту, править при апгрейдах.
4. Витрина обложек на /production/: загружены реальные релизы (Kirie, Pimp, Price, Shem Vol.1); новые кладите в assets/img/covers и добавляйте слайдом в карусель.
5. Реквизиты исполнителя в terms.html.
6. Правила переноса брони (сейчас: бесплатно за 6 часов) в terms.html и FAQ.
7. Список резидентов и кредитов на index.html и label.html взят из брендбука (июль 2025):
   проверить актуальность состава перед публикацией.
