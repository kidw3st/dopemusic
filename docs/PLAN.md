# План сборки сайта Dope Music (выполнен)

Формат по superpowers:writing-plans: цель, шаги с критериями готовности, риски. План зафиксирован как исполненная запись сборки и дорожная карта доводки.

## Цель

Многостраничный статический сайт студии звукозаписи Dope Music (Пермь) по брендбуку Behance: рассказать про студию, лейбл и продакшн, показать цены, принять заявку на бронь, дать контакты и юридические документы. Рукотворный печатный вид, ноль AI-паттернов из бан-листа владельца.

## Шаги (все выполнены)

1. Разбор брендбука: скачаны 11 разворотов, извлечены логотип, шрифтовая пара, палитра, саб-бренды, контакты, артисты. Готово: факты в PRODUCT.md.
2. Направление: мир «печатная продукция студии», структура главной: кандидат 4 из 7 (seed 05d18d51). Готово: контракт в комментарии index.html.
3. Дизайн-система: assets/css/main.css с токенами, шрифты self-hosted (Mulish, Martian Mono: cyr, lat, lat-ext с ₽). Готово: детектор impeccable без находок.
4. Страницы: index, studio, label, production, services, booking, contacts, terms, privacy. Готово: единая шапка/подвал, aria-current, метатеги.
5. Функционал: калькулятор брони (ставки, «пятый час в подарок», купон DOPE2500), валидация, черновик в localStorage, заявка через Telegram deep-link с копированием текста, слоты 24/7. Готово: booking.js.
6. Движение: вращение печати, бегущая строка, reveal с html.js-гейтом (без JS страница полностью видима), reduced-motion. Готово: main.js + main.css.
7. Проверки: headless-скриншоты десктопа и мобилы, замер переполнения iframe-пробой (scrollWidth = viewport), фиксы (latin-ext ₽, .station на узких экранах, overflow-x clip). Готово: скриншоты в scratchpad.
8. Финиш: независимое ревью субагентом, правки по его вердикту, DESIGN.md. Готово по факту вердикта.

## Риски и решения

- Нет бэкенда: заявка идёт через Telegram-ссылку; текст дублируется копированием, есть телефонный фолбэк.
- Авторские права: фото артистов и реальные обложки не используются; графика векторная своя.
- Шрифты брендбука коммерческие: подобраны свободные аналоги с кириллицей, зафиксировано в docs/brand-guidelines.md.
