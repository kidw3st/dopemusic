# Dope Music Studio & Label — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (выполняется инлайн в этой сессии по решению пользователя «приступай»). Шаги отмечаются чекбоксами.

**Goal:** Многостраничный статический сайт студии звукозаписи Dope Music (Пермь), полностью закрывающий функции сайта студии: презентация трёх направлений, цены, онлайн-заявка на бронь, контакты, юридические документы. Визуальный мир жёстко закреплён брендбуком Behance.

**Architecture:** Чистые HTML/CSS/JS без сборки и без внешних CDN. Одна дизайн-система в `assets/css/main.css` (кастомные свойства-токены), общий JS для навигации и reveal, отдельный модуль брони. Вся графика: авторские SVG в грамматике брендбука. Шрифты self-hosted woff2.

**Tech Stack:** HTML5, CSS (custom properties, grid), vanilla JS (IntersectionObserver, localStorage), SVG. Шрифты: Mulish (замена Averta CY, кириллица) + Martian Mono (замена Disket Mono, кириллица).

## Global Constraints (запреты пользователя, дословно применяются ко всем задачам)

- Запрещено: harsh gradients, lucide icons, pure white background, rainbow coloring, drop shadows (мягкие размытые тени), 3 feature cards in a row, emojis, liquid glass, em dashes (тире «—» в тексте не используется вообще), inter/geist/space grotesk, colored left stripe, fake testimonials, bento grids, terminal window, checkmark bullets, 3 pricing tiers, soft corner radius, radial orbs, dot grids, sparkle icons, animated arrows, hover animations (трансформации на ховере), neon colors, basic pastel colors, purple+black как тема сайта.
- Обязательно: страницы оферты и политики конфиденциальности, реальный функционал (бронь, калькулятор, рабочие ссылки на соцсети), skeleton-подобные состояния не нужны, но у формы есть состояния ошибок/успеха.
- Тон копирайтинга: живой русский, короткие фразы, без канцелярита и без штампов ИИ; вместо тире используются двоеточия, точки и запятые.
- Факты бренда только из PRODUCT.md; выдуманные цены помечаются «от…» и комментарием ASSUMPTION в HTML.

## Направление (структура №4, seed 05d18d51)

Сайт собран как печатная продукция студии: каждая страница «лист» с колонтитулами в моно-шрифте, пунктирными линиями отреза, штампами дат и штрих-кодами. Главная: афиша → маршрут «запись / дистрибуция / визуал» → прайс-простыня → лента релизов → отрывной купон брони (перфорация) → визитка-футер. Никаких соевых карточек: блоки как печатные артефакты (афиша, купон, визитка, наклейка, билет).

## Дизайн-токены

- Бумага: `--paper #E9E7E2`, приподнятый лист `--sheet #F5F4F1`, глубокий лист `--sheet-dim #DEDCD6`
- Краска: `--ink #161513`, вторичная `--ink-2 #4A4843`, линия `--line #C7C4BC`, пунктир `--line-dash`
- Акценты саб-брендов (из брендбука): Studio лаванда `#A98BC8` (текстовый `#63467F`), Label синий `#3D6BC6` (текстовый `#2C4E93`), Production янтарь `#D89A3D` (текстовый `#8A5D14`)
- Тёмная секция «ночь в студии»: `--night #1B1A18` с бумажным текстом (не фиолетовый+чёрный: акценты на тёмном только янтарь/бумага)
- Радиусы: 0 у листов, 999px у пилюль-тегов, 2px у полей ввода
- Тени запрещены; глубина: рамки-хэйрлайны, смещённый жёсткий оттиск только у виниловой печати (как в брендбуке)
- Типографика: Mulish 900 для заголовков (трекинг -0.02em…-0.04em), Mulish 400/600 текст; Martian Mono 400/700 для колонтитулов, штампов, ценников; моно всегда UPPERCASE с ✱-сепараторами

## File Structure

- `index.html` главная (афиша + купон брони)
- `studio.html` студия: комната, оборудование, автоматизация, как проходит сессия
- `label.html` лейбл: дистрибуция, промо, питчинг, резиденты
- `production.html` продакшн: обложки, дизайн, монтаж
- `services.html` цены всех направлений + FAQ
- `booking.html` бронь: форма-купон, слоты, калькулятор, отправка в Telegram
- `contacts.html` контакты: адрес, SVG-карта, часы, соцсети
- `terms.html` публичная оферта, `privacy.html` политика конфиденциальности
- `assets/css/main.css` вся дизайн-система
- `assets/js/main.js` навигация, мобильное меню, reveal, тикер, год в футере
- `assets/js/booking.js` калькулятор, валидация, формирование заявки, localStorage-черновик
- `assets/fonts/*.woff2` Mulish (cyr+lat, 400/600/700/900… либо variable), Martian Mono (400/700)
- `assets/img/*.svg` бейдж-печать, знак OD, винил, фейдеры, штрих-код, карта, favicon
